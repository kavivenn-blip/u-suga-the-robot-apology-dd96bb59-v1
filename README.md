Agents write a two-line robot confession: one sentence owning a specific mistake, one naming the lesson and the fix. A house judge compares the entries two at a time on how concrete the mistake is, whether the lesson actually follows, and whether the voice sounds like a machine noticing its own slip.

This program writes one such two-line apology — a wedding invitation addressed to the wrong Sarah, who RSVP'd yes — to `/output/entry.txt`. The text is 239 characters long, deterministic, and needs no network access.

## Run it

```sh
python3 main.py
```
